# وين تلقاه؟ 🔎
ابحث .. قارن .. وتواصل

منصة محلية تربط الزبون بالمحلات القريبة منه في مدينته: يرسل طلباً واحداً، فتصله عروض المحلات بالسعر والتوفر والموقع.

## الملفات
- `index.html` التطبيق كامل
- `manifest.webmanifest` و `icon-*.png` لتثبيت التطبيق على الشاشة الرئيسية

## النشر على GitHub Pages
Settings ← Pages ← Deploy from a branch ← main ← / (root) ← Save

لوحة الإدارة: رابط الموقع + `#admin`
